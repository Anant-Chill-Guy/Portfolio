# KR4K3N — Portfolio

Personal portfolio for Anant Awasthi (KR4K3N), built as an animated Spider-Verse–inspired comic.

## Stack

- React 18 + TypeScript
- Vite
- GSAP + ScrollTrigger

## Development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Production

```bash
npm run build
npm run preview
```

All artwork in `src/components/art.tsx` is original SVG. No external image assets.
